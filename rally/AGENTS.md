# Rally handoff

Follow the repository-root handoff and canonical Agon instructions. Read README.md
before edits. Use the root `.venv/bin/python`. Build/test from the root with
`make -C rally` and `make -C rally test`. The user accepted the lower viewpoint and authorized flat curves from the
supplied track map. The player car and Left/Right steering are now integrated,
with lateral inertia and outward curve slip. Kerb/grass speed penalties are enabled (160/90 tuning thresholds). Up/Down control speed.
Generate track data with `make -C rally track`; editable cubics are in `assets/tracks/*.json`. Both circuits are embedded;
normal `run` selects the tri-oval and `run . fuji` retains the earlier circuit. The prior road-only milestone is emulator/hardware validated. The current traffic
milestone is emulator-reviewed and approved for a local commit; it has not been
deployed to hardware. The card carries the earlier driving build. Remote publication is deferred. Root TODO.md owns active work.
The isolated `.emulator` profile is generated by tools/prepare_emulator.py;
run.sh delegates to its mandatory generated launcher. Future emulator-related changes require user validation and explicit commit
approval under the canonical workflow.

Steering snapshots held keys once per rendered frame and advances three persistent
256-circle angle units per frame (signed ±21); neither key repeat nor physics catch-up adds steering steps.

Current default is the flat tri-oval; preserve the selectable Fuji data.
Minus/equal adjust live grip once per frame (25–200%, 5-point increments).
Track, grip and steering were tuned through user emulator play; local milestone commit approved.

Six opponents use three fixed lanes/speeds, VDP lookup-table material-colour substitutions and VDP
Q8 scale/reflection matrices. See include/traffic.hpp; car-to-car collisions are absent.
Default grip is 60%, still live-tweakable.

Scenery: `make -C rally scenery` uses Pillow + local agon-utils nearest-palette conversion.
Generated 4-bit panorama expands via VDP command 72; draw-time scrolling uses
absolute track tangent with integer atan lookup, no parallax. See assets/scenery.
Widened kerbs and shoulder lines plus scenery await user emulator review.

Demo is the launch default; any key takes over, `run . race` bypasses it.
Escape quits after takeover. The prompt occupies the existing HUD band.
Uses normal physics with curvature-based speed control and centre correction.
The current review emulator autoexec selects demo; physical card is unchanged.

## Emulator product names

Select the name from the runtime and VDP backend: Fab uses a native host VDP;
Flexe executes actual ESP32 VDP firmware. From the profile directory, launch
Fab with `./fab-agon-emulator` and raw link `fab-agon-emulator.bin`, or Flexe
with `./flexe-agon-emulator` and raw link `flexe-agon-emulator.bin`.
Each entry must be a real generated wrapper with its existing host-library,
MOS/runtime identity and backend guards. Flexe must have no Fab-named launcher,
symlink or compatibility shim. Existing Fab launch instructions apply only to
Fab profiles. For Flexe, call the canonical setup tool's `name_flexe_profile`
after customization and before recording deployment checksums.
