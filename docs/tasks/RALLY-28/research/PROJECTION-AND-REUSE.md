# RALLY-28 — shared projection and repeated-work map

2026-10-15, released standard-first discovery for POS-001-01 / REUSE-001-01. This is a design and caller inventory, not a product change. The [capacity/census fixture](../standard-vdp/capacity/README.md) compiles the unchanged normal game. Native adoption still requires an independent audit/qualification. Existing [arithmetic](HOT-LOOP-REVIEW.md) and [lookup recovery](LOOKUP-ENGINE-REVIEW.md) evidence supplies the operation/ABI details.

## Position producers and consumers

The current renderer already shares dense `Road::centers` through `DirectRoad::centerAt`. Its problem is the amount and duplication of work surrounding that shared result. Replacing only the road emitter would leave the following consumers and costs behind.

| Consumer / source | Inputs and units | Frequency / current computation | Common result to retain or provide |
| --- | --- | --- | --- |
| Road projection, `DirectRoad::project`, `Road::project` | Camera station in hundredth world units, phase modulo8000, lateral camera offsetQ8; track coordinatesQ8, tangentQ12 | DirectRoad and base Road both sample the camera;121 dense projected rows104–224; greedy fitting repeatedly revisits intermediate rows | One camera descriptor; on-demand centreQ8 at requested depth; table depths; boundary/material list; shared final edge coordinates |
| Road band/material/edge layers, `Road::bandEnd/strip`, `DirectRoad::emitTo` | Top/bottom row, centreQ8, widths106/90/86/84/2; final pixels | Four or five quads/band; same endpoint/row conversions and width arithmetic repeated per layer; greedy search is inside emission | Cached centre and all requested edges at each actual boundary; material splits independent of geometry source; reuse adjacent endpoints |
| Opponents, `prepareGameScene` | Six wrapped longitudinal stations; lane in integer world units, route heading1/65536turn | Six distance/order tests; six visible cars in the900-frame control; q=8000/z, scale=2q; common `centerAt(y)` plus lane offset; map tangent for yaw and a separate camera sample | Shared depth/scale descriptor and camera tangent; centre/edge interface shared with signs/player; preserve route heading and visibility/order |
| Signs, `Billboards::prepare` | Track length/count; sign station, depth, alternating side;64px source art | Four candidate station calculations/frame; repeated index*lap/total, wrap and position*total/lap; same q and2q scale as cars | Track-owned precomputed stations/art/side; shared depth/scale/centre; retain sign-specific anchor/sky clip |
| Player, `prepareGameScene`, `playerCenterX/Pose` | LateralQ8, steering, row214, artwork ground anchor51/50 | One common road centre query, then lateral offset and view/reflection; crash/bink paths consume the same centre | Common centre/anchor with explicit lateral conversion; no second projection implementation |
| Finish line, `finishLine` | Wrapped distance to station0; q and row;12 checker columns, two rows | Repeats road width/centre and division12 for each checker cell when visible | Shared projected width/centre; build thirteen boundaries once/row, reuse neighbours; fixed screen clipping |
| Panorama, `prepareGameScene`, `SceneryHistory` | Camera tangentQ12 →1024-unit heading, per-page prior heading | Another camera sample, atan lookup and signed wrap; absolute heading transformed to two retained-page deltas | Shared camera tangent/heading; page history remains separate from geometry cache |
| World physics/contact, `Motion::tick`, `RaceTraffic` | Actual tick state, fractional stationQ8, tangents64world units apart; world lateralQ8 | Per physics tick, independently of rendered snapshots | Separate world sampling service where useful; never substitute projected pixels or a stale frame cache for contact/physics |

`prepareGameScene` currently samples scenery heading at the fractional station, but traffic camera/yaw at `position/100*256` (fraction discarded). Traffic's opponent tangent similarly discards the fractional station. The physics uses the fractional station. Preserve both sampling policies explicitly for an exact control, or disclose adopting one visual sampling policy as an approximation. Reusing a convenient camera value without recording this difference changes yaw/background behavior. Signed division truncates toward zero; shifts of negative values differ. Q8 at the Fuji lap boundary plus lookahead also exceeds signed24-bit range; do not narrow the entire route expression just because final screen coordinates are small.

## Proposed common interface and lifetime

A task-owned standard derivative should expose `beginFrame(snapshot, trackTables)`, `depthAtRow(row)`, `centerQ8At(row)`, `edgeAt(row,width)`, `poseAtDistance(z)` and a band/material iterator. `poseAtDistance` returns q/scale/ground row; object anchors and clipping stay explicit. These are a contract sketch, not implemented API names. Choose the lookup or sparse/coarse producer behind this interface without changing every consumer. Cache rows and map lines actually requested by road boundaries, cars, signs, player and finish; do not fill121 rows simply to populate a cache.

Invalidate the frame cache on each new immutable snapshot, track/table selection, camera/position/offset/phase or projection-policy change. Share adjacent endpoints within that frame. Track/sign/depth/width tables outlive frames and change only with track/mode/projection configuration. Physics state advances separately while an in-flight snapshot and its VDP parameter buffers remain immutable. Double-buffer page histories for sky/HUD/panels/footers survive across alternate frames; invalidate those histories on mode/phase/track changes and explicit erases. A completed frame releases its parameter plane; it does not authorize reusing stale physics geometry.

## Other incomplete optimization families

| Family / existing win | Remaining compatible callers | Required treatment and exception |
| --- | --- | --- |
| Shared route cursor/sine already used by six cars | Route placement, view and contact/passing/rank wrappers | Preserve the one-sine-per-tick design. Do not replace it with six independent route evaluations while reorganizing the renderer. World wrap can use bounded corrections where invariants are proved; public general normalization still needs full signed semantics |
| `stationSeparation` already avoids modulo | `Crash::tick/contact`, sign stations, finish distance and camera/traffic conversion | Audit valid range for each call; normalize once and reuse. Recovery currently calls general `contact(playerProgress, lane)` for up to five lanes; reuse a normalized station where exact. Do not pass a camera station where rules use player progress |
| Lookup engine already caches map coefficients and band endpoints | Every consumer in the producer table | Recover cache/endpoint reuse as a family; preserve table generation provenance and memory cost. Current dense `DirectRoad` does not use that engine |
| HUD retained cells avoid unchanged wire bytes | Formatting of top score, countdown, lap clock, score/speed/rank; development text | Cache values/formatted fields before `snprintf`, separately track which page needs emission. A cache hit must avoid formatting as well as avoid bytes. Keep changed lap/time/phase/records correct |
| Panel signatures already skip unchanged pages | Signature formatting; bottom/footer; road's bottom black rectangle | Cache phase/count/track/mode/grid inputs. The unchanged attract footer is still resent38B/frame because road redraw erases its region every frame. Remove redundant erase plus redraw together, with two-page initialization/invalidation; caching only the text would erase it |
| Audio already sends only changed pitch | Per-frame frequency arithmetic and future RPM/volume state | Preserve changed-only traffic; actual control updates must follow chosen physics/input deadlines. Do not replace it with a steady seven-byte packet each tick |
| Static palette/bitmap/font assets already resident | Repeated matrix/reset/viewport commands and full road coordinates | Add simple resident draw templates/parameter planes where complete patch+CALL costs win. Small isolated draw commands often cost fewer bytes directly. Count interpreter/copy cost, setup and memory as well as wire savings |
| Sign station/lap invariants still recalculated | Sign visibility/art/side; lap products; finish width grids | Compute track/configuration constants once; cached samples/half widths must use the same frame lifetime as road/object geometry |
| Sorting/visibility and matrix work | Six cars and sign merge; per-object scale/reflection/state | Preserve depth order and sky exclusion. Compare small fixed-array sort versus maintaining order; cache unchanged matrix state only with valid lifetime/ownership, including changes made by other draws |

## Ranked next experiment

1. Build the **shared lookup/sparse projection derivative** across road, cars, signs, player, finish and panorama, retaining its existing map-line cache and sparse requested-row behavior. Include a coarser-band variant as an explicit speed/appearance option. The new CPU sink demonstrates that both preparation and greedy/vertex emission are substantial; replacing only track sampling misses the larger emission work.
2. Prototype **simple road parameter planes and resident draw templates**, with all final coordinates computed on eZ80. The complete upstream model saves about52% of existing road bytes; copying/interpreting resident commands could offset that saving, so measure actual completed pipeline behavior. The recovered conservative lookup emits33% more direct road bytes, making wire reduction a useful companion experiment rather than assuming lookup alone wins.
3. Apply the chosen reuse pattern to every compatible family above, with bounded exceptions recorded, and measure actual UART/CTS blocking and completed drawing before selecting a physics cadence. Smaller viewport/footer/object wins can then follow without obscuring the dominant road costs.

This tranche supplies the standard map and nominated experiment. REUSE-001-02/03/04 implementation, native application and the new scheduler remain pending release/review. No old timing fixture, game source or pixel-accuracy gate was changed.
