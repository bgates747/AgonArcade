## Reference and scaffold boundaries

The independent model imports only immutable tables. The observer imports frozen C++ headers and never calls the Python implementation. [Verification](reference/verification.json) compares 1,800 route ticks, all 65,536 headings, 504 contact boundaries, six spawn cases, ten traffic streams totaling 192,000 ticks and selected lookup projections under ASan/UBSan. Complete per-tick streams are compared; compact published checkpoints and full-stream hashes let Golem reproduce them. Spawn/despawn/finish/slot reuse are exercised. Contact is only the old predicate: no new collision event, removal/reintroduction, countdown, sparse prediction or scheduler policy is invented. Surviving traffic continues under the reference, but new struck-car removal is not qualified.

[Root-v1](ROOT-V1.md) is accepted. `reference/root_adapter.py` uses a normalized internal interface object, validates declared metadata and completion, and supplies a deliberately labelled host stub. Its synthetic test IDs are not production reservations. A parser for Golem's external generated manifest, compiler/scalar artifact verification and actual target invocation await delivery. Host checks model native bounds; they perform no SDK leases, task synchronization or UART transport.

The next handoff is Golem's generated manifest/initialized bytes, pinned compiler build/toolchain and scalar native/buffered artifact receipt. Later game/firmware choices and human review gates remain open. No new work from this tranche has been committed or pushed.
