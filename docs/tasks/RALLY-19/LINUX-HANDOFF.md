## Golem relevance and traps

The project already compiles source into stock VDP buffer programs. Its README
and portions of AGENTS are stale: current src/golemc.cpp supports declarations,
assignment/addition, print and For/Next. loop_golem/loop.golem is a real example.
Read design/language-type-proposals.md and lifecycle/loop/devtool devlogs before
inventing another IR/loader. Golem is C++, not a Python compiler project.

Its old “command 34 1x1 invert” idea is unverified and does not match the listed
operations. RALLY-19 instead proposes reciprocal through command 32 inversion
of diag(d,1,1), then multiplication. Keep conjecture separate from tested behavior.
Some Golem loop diagnostics used instrumentation: distinguish semantic evidence
from stock-runtime performance. Preserve existing dirty files and ownership.

## Next contract, once authorized

The target is compact player progress/lateral/steering plus competitor positions
sent to resident VDP programs/data. Store stripe pitch once; calculate boundaries
and pattern parity locally, preserving lap-independent stripe phase. HUD may
need extra state. Exact packet/atomic update design remains open.

Stock commands expose matrix products, rotation coefficients, inversion and
transforms of stored PLOT coordinates. Variables are 16-bit state; float work
belongs in buffers. Verify tiny arithmetic-to-drawing kernels first, then one
section. Command 41 copies buffers; batching/allocation cost needs measurement.
An affine map does not automatically do perspective division or map a rectangle
into an arbitrary trapezoid. Existing compact lookup coefficients may be the
best initial VDP workload. Do not restore unnecessary expensive geometry math.

road/vehicle masks separately from sky; all expected objects/materials present;
selected poses include both tracks, seams, bends, lateral extremes and overlap.
Our proposed 1px geometry/95% regional pixels threshold is provisional. Test
that the metric rejects missing cars/markings and tolerates harmless edges.
Freeze a separate performance threshold; none is agreed yet. Turing completeness
alone says nothing about useful speed. Grow Golem only for measured Rally needs.
