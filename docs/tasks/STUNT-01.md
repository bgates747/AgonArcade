# STUNT-01 — Future stunt racer

Separate future AgonArcade game inspired by Stunt Car Racer, using custom Pingo
VDP true 3D and flat-shaded triangles. Implementation has not started. This task
does not relax Rally's stock-VDP shipping requirement or replace current Rally work.

First qualify the renderer/examples and their current protocol/ABI, then a small
elevated track with one ramp. Use a sibling game directory and its own generated
emulator profile; preserve donor repositories. The design context and reference
examples are in the [project brief](../plans/stunt-racer.md). Root TODO.md owns
status. Agree on initial experiment scope when this future task is selected.
